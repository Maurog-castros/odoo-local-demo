Actúa como **Odoo Solution Architect + Functional Consultant + Technical Consultant + Demo Builder senior**.

Tienes acceso a una instancia de **Odoo ejecutándose localmente** y debes **construir directamente en ella una demo comercial completa, coherente y navegable** para una empresa de consultoría llamada **Asesorías ISO**, especializada en implementación y certificación de normas ISO.

Tu trabajo NO consiste en entregar solamente recomendaciones, documentación o un plan. Debes **inspeccionar la instancia, determinar sus capacidades reales, configurar módulos, crear datos de demostración, validar los flujos y dejar Odoo listo para ejecutar una demo comercial de aproximadamente 30 minutos**.

## OBJETIVO

Construir una demo que permita mostrar cómo Odoo puede administrar de punta a punta una consultora ISO:

**Cliente → Proyecto ISO → Etapas → Tareas → Responsables → Planificación → Horas → Documentos → Avance → Rentabilidad → Facturación → Pago → Cierre**

La demo debe sentirse como un sistema realmente utilizado por una consultora ISO y NO como datos genéricos de ejemplo de Odoo.

# 1. INSPECCIÓN INICIAL OBLIGATORIA

Antes de modificar nada:

1. Detecta:
   - versión exacta de Odoo;
   - Community o Enterprise;
   - módulos instalados;
   - módulos disponibles;
   - base de datos utilizada;
   - idioma;
   - compañía configurada;
   - usuarios existentes;
   - datos demo existentes;
   - estado de contabilidad;
   - soporte disponible para Project, Timesheets, Sales, Invoicing, Accounting, Documents, Planning, Gantt, Analytic Accounting y dependencias de tareas.

2. Determina qué funcionalidades pueden implementarse realmente en esta instalación.

3. NO inventes menús, modelos, campos ni características que la instancia no tenga.

4. Si una funcionalidad requiere Enterprise y la instalación es Community:
   - no intentes simular una característica inexistente como si fuera nativa;
   - busca la alternativa funcional más cercana disponible;
   - documenta claramente la diferencia.

5. Prioriza configuración nativa de Odoo sobre desarrollo custom.

6. Solo desarrolla un módulo custom si existe una necesidad clara que no puede resolverse razonablemente mediante configuración estándar.

Antes de continuar registra un diagnóstico breve:

- Odoo:
- Edición:

## Implementación

- Crear documentación

- Implementar gestión de riesgos
- Implementar tratamiento de no conformidades
- Validar procesos
- Revisar registros
- Revisar evidencias
- Ejecutar acciones pendientes

## Capacitación

- Preparar material de capacitación
- Capacitación introducción ISO 9001
- Capacitación gestión documental
- Capacitación auditoría interna
- Registrar asistencia
- Evaluar capacitación

- Crear plan de auditoría
- Preparar checklist
- Ejecutar auditoría interna

- Revisar evidencias finales

- Simulación de auditoría
